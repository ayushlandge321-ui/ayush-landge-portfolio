# Ayush Landge — Personal Portfolio

A responsive dark-themed portfolio built with plain HTML, CSS, and JavaScript. No build tools or external libraries are required.

## Preview locally
1. Download and extract this ZIP.
2. Open `index.html` in a browser.

## Publish with GitHub Pages
1. Sign in to GitHub and create a repository named `ayushlandge321-ui.github.io` (replace with your actual GitHub username).
2. Upload `index.html` and this `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, then select the `main` branch and `/ (root)`, and save.
5. After deployment, open `https://ayushlandge321-ui.github.io`.

Official instructions: https://docs.github.com/en/pages/quickstart
